We added three new ADRs to document core project strategy:

- unified curation of etc + misc rules
- generated rule catalog metadata as the docs source of truth
- risk-tiered recommended preset strategy

<!-- truncate -->

These records make it easier to reason about why the plugin is shaped the way
it is and reduce context loss for future maintainers.

We also introduced supporting guides for migration, docs maintenance, and blog
planning so architecture decisions can flow into contributor workflows and
release communication.
